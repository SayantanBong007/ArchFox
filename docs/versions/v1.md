# v1 — Basic scaffold

## What was built
The initial project skeleton, with no AI wired up yet — just the shape of the app.

- `apps/cli/main.py` — CLI entrypoint
- `agents/reviewer/reviewer_agent.py` — `ReviewerAgent` class, stubbed
- `tools/github/github_client.py` — `GitHubClient` stub for talking to GitHub
- `prompts/review_prompt.py` — `SYSTEM_PROMPT` (the reviewer's instructions)
- `configs/settings.py` — reads secrets from environment variables
- `pyproject.toml`, `.gitignore`, `.env` / `.env.example`

## Key files touched
`pyproject.toml`, `configs/settings.py`, and the five package folders above.

## What I learned
- What `pyproject.toml` is for, and why a project needs it (metadata, dependencies, the `archfox` command).
- What a Python virtual environment (`.venv`) is and how to activate it on Windows.
- Why `.env` holds secrets and why it's gitignored, while `.env.example` documents which variables are needed without the real values.
- Basic package structure: every importable folder needs an `__init__.py`.
