# ArchFox v8: The Fixer & Chat pipeline 🦊🔧

Welcome to ArchFox v8! In this version, we stabilized the new interactive Chat Pipeline and squashed several tricky bugs across the codebase.

## 1. Webhook Chat Pipeline & True PR Context 💬
In v7, we built a webhook listener to talk to ArchFox on GitHub, but it was running blind! The AI could search the repository, but it didn't actually read the code you were changing in your Pull Request. 

**What we changed:**
- Built `tools/github/github_client.py:get_pr_diff` to fetch the raw `git diff` of any PR over the GitHub API.
- Integrated the Diff directly into the `ChatAgent`'s brain. Now, when you ask `@archfox why is this line wrong?`, it can actually read your code changes and give you a precise answer!
- Created a brand new LangGraph pipeline specifically for chatting (`graphs/chat_graph.py`), separating it from the heavy Code Review pipeline.

## 2. CLI GitHub URL Parsing Fix 🐛
When running the local CLI, users sometimes provided repository URLs ending in `.git` (e.g., `https://github.com/SayantanBong007/ArchFox.git`). The CLI would incorrectly parse the repository name as `ArchFox.git`, which broke the GitHub API!

**What we changed:**
- `apps/cli/main.py` now explicitly strips out `.git` from the end of URLs, gracefully handling both standard web URLs and Git clone URLs.

## 3. Pytest Teardown Crash Resolved 🧪
When running `pytest`, the test suite would finish successfully but then throw a massive `ValueError: I/O operation on closed file` crash during teardown. This was caused by our global `configs/logger.py` fighting with Pytest's standard output interception.

**What we changed:**
- We taught the logger to detect when it's being run inside Pytest (`"pytest" not in sys.modules`). When testing, ArchFox now silences its terminal loggers and lets Pytest handle standard output, resulting in clean, crash-free test runs!

## 4. Prompt System Modernization 🧠
The `ChatAgent` was previously using an outdated, hardcoded prompt hidden deep in its Python logic. 

**What we changed:**
- Extracted the Chat AI logic into `prompts/chat_prompt.py`, standardizing it with the rest of our advanced prompt engineering system.

---

ArchFox is now more stable, more conversational, and more aware of your exact code changes than ever before!
